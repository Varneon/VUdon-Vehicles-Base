Common vehicle descriptors, assets, prefabs and editor scripts for VUdon - Vehicles (Lite & Full)

>[!IMPORTANT]
>This repository does ***NOT*** contain a drivable vehicle prefab! This repository is a set of non-destructive tools for constructing a source vehicle definition with all necessary data for generating a prefab by another package.
