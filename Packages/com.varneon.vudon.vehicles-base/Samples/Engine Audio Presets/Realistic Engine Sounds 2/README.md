This folder contains engine audio preset data proxies for Realistic Engine Sounds 2 by Skril Studio on Unity Asset Store.

The preset ScriptableObjects only contain references to the assets contained in RES2 packages in order to make the data compatible with VUdon Vehicles - Lite CarController without the need for having the C# assembly of RES2 being included in the project.

In order to utilize the preset(s), purchase the engine audio pack(s) you wish to use for the vehicles, and import the pack into this project and the presets will reference the assets automatically, making them available to be used in the LandVehicleDescriptor.

Skril Studio also offers free packs so you can try them out first before making a purchase.

Q: Are you affiliated with Skril Studio?
A: No. They just happen to have the highest quality, most consistent engine audio packs available for a reasonable price on the Unity Asset Store and I've personally used their assets for 7+ years
